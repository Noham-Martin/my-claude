# STATE.md Template

Use this structure for `.planning/STATE.md`. Keep it under 100 lines.

```markdown
# State

Last updated: YYYY-MM-DD
Branch: <current branch>
Session: <path to latest session file>

## Current Focus
<1-2 lines: what you are working on right now>

## Key Decisions
- <most important recent decisions with brief rationale>

## Next Steps
1. <first priority>
2. <second priority>
3. <third priority>

## Blockers
- <anything blocking progress, or "None">
```
