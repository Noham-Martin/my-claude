# Session File Template

Use this structure for `.planning/sessions/YYYY-MM-DD-<label>.md`.

```markdown
---
date: YYYY-MM-DD
branch: <current branch>
label: <label>
---

# Session: <label>

## Accomplished
- <what was completed this session>

## In Progress
- <what is partially done, with file paths and line numbers>
- <current state of each in-progress item>

## Decisions Made
- <decision>: <rationale>

## Blockers & Open Questions
- <anything unresolved>

## Mental Context
- <the "why" behind the current approach>
- <things that aren't obvious from the code alone>
- <gotchas the next session needs to know>

## Git State
- Branch: <branch>
- Uncommitted changes: <list or "none">
- Recent commits: <last 3-5 commits>

## Next Steps
1. <first thing to do when resuming>
2. <second thing>
3. <third thing>
```
